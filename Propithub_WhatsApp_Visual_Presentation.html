Immediate Step-by-Step Implementation Plan

A structured, low-risk sequence to bring WhatsApp automation live to Propithub.

Step 1 • Foundation

Meta API & Webhook

  • Register WhatsApp Business Cloud API under Meta Developer Console
  • Add `/whatsappWebhook` HTTPS endpoint in Firebase Cloud Functions
  • Complete verification challenge
Step 2 • Identity

User Role Resolver

  • Match incoming sender phone number against Firestore `/users`
  • Automatically load Owner, Tenant, or Staff permissions
  • Implement session state machine for multi-step prompts
Step 3 • Approvals & Payments

Core Operational Flows

  • Deliver lease agreement PDF with `[Approve]` and `[Reject]` buttons
  • Connect daily rent sweeps to WhatsApp interactive payment cards
  • Automate tax receipt PDF dispatch on settlement
Step 4 • Growth Funnel

Omnichannel Marketing

  • Generate tracking deep links (`wa.me/?text=TRIAL_INSTA`)
  • Auto-provision 14-day free trial on first chat
  • Deploy offline QR codes for print and expo banners
